CF7 → Google Sheets

WordPress plugin that syncs Contact Form 7 submissions directly into Google Sheets — no additional plugin dependencies.

What It Does

  • 🔗 Zero WP plugin deps — only needs Contact Form 7 + Google API
  • 🗺️ Field mapping UI — drag to map form fields to sheet columns
  • 📎 Uploads & checkboxes — handles file uploads and multi-select fields
  • 🛡️ Silent failure — logs errors, never breaks the form
  • ⚡ Google Apps Script — pure JS backend, no PHP API calls

Tech Stack

PHP WordPress Google API JavaScript
