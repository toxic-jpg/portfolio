Three common layout bugs — toggle to see the fix

Bug #1: Flexbox Gap + Overflow

Card 1
Card 2 with longer content
Card 3
What was broken?

Bug: `gap` on flex container + long content = overflow on mobile.

Fix: `min-width: 0` on flex children + `overflow: hidden` on container.

Bug #2: Absolute Center in Relative Parent

Centered
What was broken?

Bug: `top: 50%; left: 50%` without `transform: translate(-50%, -50%)` centers the top-left corner, not the element.

Fix: Add `transform: translate(-50%, -50%)`.

Bug #3: z-index Stacking Context Trap

Modal Dialog

This should be ABOVE the backdrop.

Sticky Header (z-index: 100)
What was broken?

Bug: Modal inside a stacking context (parent with z-index) can't escape above sibling with higher z-index.

Fix: Move modal to body (portal) OR remove z-index from parent creating the context.
