# Portfolio

A clean, single-page portfolio website for Heart — BSIT student and software developer.

## Quick Start

```bash
# Open directly in browser
start index.html

# Or serve locally
python -m http.server 8000
# Then open http://localhost:8000
```

## Deploy to GitHub Pages

1. Push `index.html`, `styles.css`, and all subfolder projects to a GitHub repo
2. Go to repo **Settings → Pages → Source** and select `main` branch
3. Your portfolio will be live at `https://yourusername.github.io/repo-name/`

## Tech Stack

- Pure HTML5 + CSS3 (no frameworks)
- Google Fonts: Inter + Space Grotesk
- Vanilla JS for mobile nav only
- Responsive (mobile-first breakpoints)
- Accessibility: skip link, ARIA labels, keyboard navigation, reduced motion support
