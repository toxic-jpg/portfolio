# Design

## Visual Authority
Game Inventory / Character Sheet aesthetic.

- Palette: Dark mode based (#09090b), accent #3B82F6, unlit segment ghost-border for empty states.
- Type: Monospace hierarchy, fixed-cell alignment.
- Topology: Rigid grid, no reflow per-glyph.
- Interaction: Hover reveals item tooltip (project stats), clicking equips (view demo).

## Components
- Inventory Grid: 3-column fixed layout.
- Project Card: Item slot with stats (LOC, tests), tech ribbons (attached labels).
- Call to Action: The "Hire Me/Buy" interaction (the "colon" in the seven-segment metaphor).
