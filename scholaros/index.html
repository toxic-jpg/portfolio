ScholarOS

Modular academic dashboard — GPA tracking, risk prediction, auto-generated study schedules.

What It Does

  • 📊 GPA tracking — per course, per term, cumulative
  • ⚠️ Risk prediction — flags courses trending toward failure
  • 📅 Study schedules — auto-generated based on exam dates and difficulty
  • 🔌 FastAPI REST API — full CRUD for all entities
  • 🖥️ Tkinter desktop GUI — native Windows app

Tech Stack

Python FastAPI SQLite Tkinter pytest

How to Run

# Install
pip install -e .

# Run API server
python -m scholaros.api.app

# Run desktop GUI
python -m scholaros.gui.dashboard
