PennyPinch

A zero-dependency CLI personal finance tracker. Log income and expenses, categorize spending, generate monthly reports — all backed by a single JSON file.

What It Does

  • 💰 Log entries — income, expenses with category and notes
  • 📊 Monthly reports — category-wise breakdown with totals
  • 🔍 Filter — by category and date range
  • 📁 Zero deps — pure stdlib Python + JSON persistence
  • 🖥️ CLI-first — pennypinch --help

Usage Examples

pennypinch add expense 12.50 --category groceries --note "weekly shop"
pennypinch add income 1000 --category salary
pennypinch list --category groceries --from 2026-01-01
pennypinch report

📦 Published on PyPI via GitHub repo. Install with pip install pennypinch
