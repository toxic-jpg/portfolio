CSV Data Cleaner

Python tool that scrubs, validates, and transforms messy CSV/Excel files into clean, usable data.

What It Does

  • 🧹 Missing values — detect, impute, or flag gaps
  • 🔄 Type fixing — dates, numbers, enums auto-detected
  • 🗑️ Deduplication — find and remove duplicate rows
  • 📧 Email reports — send cleaned output + summary
  • 📊 Excel support — reads .xlsx via openpyxl

Tech Stack

Python pandas openpyxl smtplib

🎯 Freelance deliverable — built for a client on r/forhire. Real-world cleaning pipeline.
